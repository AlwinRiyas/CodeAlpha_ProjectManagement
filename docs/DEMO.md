# Demo Walkthrough

## 1. Authentication

Register a user or use the seeded demo account.

## 2. Project

Create a project and open the generated Kanban board.

## 3. Team

Add another registered user to the project.

## 4. Tasks

Create tasks, assign them to members, set priorities, and move them between columns.

## 5. Collaboration

Open a task, add comments, and observe activity/notification events.

## 6. Real-time behavior

Open the project in two browser sessions and make a task change in one session. Authorized clients receive Socket.IO updates without a full page refresh.
