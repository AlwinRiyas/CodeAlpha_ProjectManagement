# Project Overview

## Problem

Small teams need a shared place to turn project goals into visible, assignable work without switching between separate task, chat, and notification tools.

## Solution

ProjectFlow combines project workspaces, Kanban tasks, assignment, task comments, activity history, notifications, and real-time updates behind authenticated APIs.

## User flow

```text
Register / Login
      ↓
Create or open a project
      ↓
Add team members
      ↓
Create and assign tasks
      ↓
Move tasks through the Kanban board
      ↓
Comment inside tasks
      ↓
Receive live notifications
```

## Portfolio value

The project demonstrates full-stack application architecture, relational data modeling, authentication, authorization, API validation, real-time communication, frontend state handling, containerization, CI, and software-development workflow practices.
