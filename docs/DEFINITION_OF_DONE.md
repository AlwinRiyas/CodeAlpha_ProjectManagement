# Definition of Done

A change is ready to merge into `development` when:

- [ ] The implementation matches the intended behavior.
- [ ] Authentication and authorization are preserved.
- [ ] Input validation exists for new request data.
- [ ] Error paths return safe, useful responses.
- [ ] Relevant tests are added or updated.
- [ ] Server build passes.
- [ ] Client build passes when the UI changes.
- [ ] Documentation is updated when behavior or setup changes.
- [ ] No secrets or generated local state are committed.
- [ ] The PR explains testing and notable trade-offs.
